# AI Lecturer User Documentation

---

## 📘 Overview

AI Lecturer is an intelligent web-based platform that allows educators and students to automatically generate complete digital lectures—including slides, narrated videos, quizzes, and Q\&A chat support—from a single topic input.

It is built using **React.js** (frontend) and **FastAPI** (backend), integrated with tools such as **GPT-4**, **gTTS**, **Reveal.js**, **Playwright**, and **MoviePy**.

### Key Benefits:

* Automates lecture creation
* Reduces manual effort
* Enhances learning with multimedia content
* Intuitive and accessible for all learning levels
* Supports schools, universities, and corporate training environments

---

## 🚀 Key Features

* 🎓 Topic-based lecture content generation using GPT-4
* 🎤 AI-narrated video creation with text-to-speech
* ❓ Auto-generated quizzes with interactive feedback
* 💬 Topic-specific Q\&A chatbot assistant
* 🗂️ Dashboard to view and download past lectures
* ➗ Math-friendly narration using GPT-4 prompting tricks
* 🔁 Multi-attempt quiz system for retention and self-evaluation

---

## 🔐 1. Login Page

* Users land here on app launch.
* Enter your **email** and **password** to sign in.
* Optionally check **"Remember Me"** to stay logged in.
* Click links to **reset password** or **create a new account**.

---

## 🧾 2. Sign-Up Page

* New users can register by entering:

  * Email address
  * Password (with confirmation)
* Upon successful sign-up, users are redirected to the main app.

---

## 🏠 3. Lecture Generation Page (Home)

* Enter your topic (e.g., `LLMs in 1 sentence`).
* Click **Generate Lecture Content**.
* Preview the output and click **"True"** to confirm.
* The system creates:

  * Reveal.js slides
  * Narration using TTS
  * Final **MP4 video** combining slides and audio
* A **Q\&A Chatbot** appears to answer topic-related questions.

### 🔄 Navigation Panel:

* **Home**: Generate a new lecture
* **Lectures**: View/download your saved videos
* **Logout**: Exit the app

---

## 📝 4. Quiz Tab

* Switch to the **Quiz** tab from the Lecture panel.
* Click **Start Quiz** to attempt a 5-question quiz auto-generated by GPT-4.
* Users get up to **3 attempts** to improve scores.

---

## 🎞️ 5. Lectures Page

* Displays all previously generated lectures as tiles.
* Each tile includes:

  * **Preview video**
  * **Download button**
* File names match the lecture topic.

## ⚙️ Technology Stack

| Tool / Technology    | Purpose                   | Role in Project                                        |
| -------------------- | ------------------------- | ------------------------------------------------------ |
| GPT-4 API            | Content & Quiz Generation | Creates slides, narration, quiz, and chatbot responses |
| Reveal.js            | Slide Rendering           | Converts content into HTML-based slides                |
| gTTS                 | Text-to-Speech            | Converts narration text to audio                       |
| MathReader Prompting | Math Narration            | Rewrites math expressions for verbal clarity           |
| Playwright           | Slide Screenshots         | Captures slides from Reveal.js as images               |
| MoviePy              | Video Compilation         | Combines images + audio into lecture videos            |
| Mutagen              | Audio Sync                | Reads audio duration to sync visuals                   |
| React.js             | Frontend                  | Handles user interface and interactions                |
| FastAPI              | Backend                   | Orchestrates API calls and processing                  |
| JSON                 | Data Exchange             | Sends data between frontend & backend                  |
| Gradio (Dev Only)    | UI Prototyping            | Used during development for testing                    |
