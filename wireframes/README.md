# Wireframes

This directory contains the high-fidelity wireframe designs for our AI Lecturer web application. These wireframes serve as visual blueprints for the main user interfaces, guiding both front-end development and user experience decisions.

---

## File Structure

| File Name                   | Description                                                                                  |
|-----------------------------|----------------------------------------------------------------------------------------------|
| **loginpage wireframe.pdf** | Sketch of the login and registration page, illustrating user authentication flows.            |
| **Lecture & Quiz Page.pdf** | Layout of the lecture delivery page, including embedded video, transcript, and quiz interactions. |
| **Gradio Interface.pdf**    | Sample Gradio-Interface . |


---

## Individual Wireframe Descriptions

### 1. `loginpage wireframe.pdf`
- **Purpose:** Allows users (students and instructors) to securely log in or create a new account.
- **Key Elements:**
  - Email and password fields
  - "Forgot password" link
  - "Sign up" option for new users

### 2. `Lecture & Quiz Page.pdf`
- **Purpose:** Delivers the generated lecture content and embeds interactive quizzes to assess comprehension.
- **Key Elements:**
  - Video player 
  - Quiz section with multiple-choice questions
  - Chatbot

---

## How to Use
1. **View the wireframes**: Download and open each PDF to inspect layout, element placement, and user flows.
2. **Reference during development**: Use these designs to implement corresponding React components and style with Tailwind CSS.
3. **Feedback cycle**: Share with stakeholders for review, annotate desired changes, and iterate on the designs.
